# v0.8.6 Full Audit Response

This record maps the independent post-release v0.8.6 findings to the focused
v0.8.7 engineering candidate. The immutable v0.8.6 GitHub and OpenAI Plugin
Directory releases remain historical records. v0.8.7 is not validated or
published until local, CI, independent-review, and external Windows canary
gates pass.

## High Findings

| Finding | v0.8.7 disposition | Deterministic evidence |
| --- | --- | --- |
| Interpreter option values appeared safely constrained | Fixed with conservative interpreter-specific operand parsing; only recognized fixed execution operands qualify | Five option-value false-safe cases plus PowerShell `-File` negative control |
| Host inventory could rewind lifecycle time or rank | Fixed: every mutation uses timestamp/rank ordering and rejected input preserves clocks and revision | Older inventory and equal-timestamp lower-rank regressions |
| Global mutex could silently fall back to Local | Fixed: shared supervision state fails closed when the Global mutex is unavailable | Static namespace contract plus live contention and fallback-queue tests |
| Task generation was discarded or coalesced | Fixed: supervision persists generation; Heartbeat baselines, conditions, recovery, and interventions bind compatible generation | Same ID/new generation produces a distinct condition and intervention |
| Planned or claimed interventions were not resumable | Fixed: one Governor can list bounded active records and reclaim an expired claim without raw task IDs | Restart list, claim persistence, expiry, and reclaim tests |
| Public verification accepted the wrong state or internal engine identity | Fixed: only `verification_pending` or `active_violation` accepts allowlisted host evidence; internal recovery remains cycle-only | Queued, claimed, and public-engine rejection plus valid native recovery |
| Governor state lacked reparse and hard-link containment | Fixed with canonical root checks, reparse-ancestor rejection, final-directory checks, and leaf link-count enforcement | Reparse parent, hard link, path escape, and normal write tests |

## Medium Findings

| Finding | v0.8.7 disposition | Deterministic evidence |

## Unchanged Boundaries

v0.8.7 does not change warning or critical thresholds, scoring weights,
predictive claims, model pricing claims, shared-folder write delegation, or the
one-Governor topology. Chronos creates no OS scheduled task, daemon, service,
publisher telemetry, or persistent diagnostic log. Host task and automation
tools remain the authority for liveness, recurrence, transport, and model-role
verification.
